# ESP32---Node-RED-Temperature-Humidity-Logger
Dashboard Monitoring Suhu dan Kelembapan Real-Time Berbasis IoT (ESP32, MQTT, &amp; Node-RED)

1. Proyek ini adalah sistem Internet of Things (IoT) full-stack yang dirancang untuk melakukan pemantauan suhu dan kelembapan secara real-time menggunakan sensor DHT11. Sistem ini mengintegrasikan mikrokontroler, protokol komunikasi nirkabel MQTT, server lokal Node-RED, basis data relasional MySQL, serta antarmuka dashboard interaktif yang dilengkapi fitur manajemen data dan ekspor laporan ke format CSV.   

2. Arsitektur & Alur Sistem (Workflow)Pengumpulan Data (Edge Device): ESP32 mensimulasikan pembacaan data suhu dan kelembapan dari sensor DHT11.   Komunikasi Protokol (Broker MQTT): Data dikirim secara nirkabel menggunakan protokol MQTT melalui broker publik (HiveMQ) agar dapat diakses dari jarak jauh.Backend & Pemrosesan (Node-RED):Menerima aliran data (subscribe) dari MQTT.   Menyimpan data secara otomatis ke database MySQL.   Memproses parameter waktu menggunakan JavaScript untuk kebutuhan filter data dan pembuatan laporan.Frontend & Database: Menggunakan MySQL untuk penyimpanan jangka panjang dan Node-RED Dashboard (UI) untuk visualisasi data berupa Gauge, Grafik (Chart), serta Tabel riwayat.   Ekspor Data (Reporting): Fitur kustom untuk mengunduh rekapitulasi data historis berdasarkan rentang waktu tertentu langsung ke format file .csv di direktori lokal.

3. Teknologi yang Digunakan (Tech Stack)Hardware / Simulasi: ESP32, Sensor DHT11 (Wokwi Simulator).   Komunikasi: MQTT Protocol, HiveMQ Broker.   Backend / Logika: Node-RED, JavaScript (Node.js).   Database: MySQL / phpMyAdmin.   Frontend: Node-RED Dashboard (UI Components).

4. Kompetensi & Keterampilan yang Dibuktikan (Key Learnings)Pemrograman mikrokontroler dan integrasi sensor lingkungan.Penerapan arsitektur IoT berbasis Publish-Subscribe (MQTT).Desain dan manajemen alur data (data flow) menggunakan Node-RED.Pengelolaan basis data SQL (koneksi, query pencarian data dinamis berdasarkan rentang waktu, hingga operasi hapus data).   Pembuatan User Interface (UI) dashboard yang informatif serta pemrograman logika manipulasi data string/array untuk ekspor file CSV.   Kemampuan debugging sistem, penanganan error kode (seperti penanganan syntax error dan tipe data), serta konfigurasi direktori sistem file.
